## Recipe validation middleware 
#### This app lets users send recipes to the server. Since the data comes from the user, it can easily be wrong or messy, for example missing a title, empty ingredients, or a lot of extra spaces. The middleware solves this by checking that the recipe has the required fields and by cleaning up the data before it reaches the API. If the recipe is invalid, the request is stopped early. If it is valid, the API gets a clean and consistent recipe object.
