# GDPR
This app will only collect the minimum amount of data requierd to function. The following data is collected:
- Username
- Hashed password
- Confirmation that the user has agreed to the terms of service

No sensitive personal data is collected. All data is currently stored in memory and is not persisted. A database solution will be added later.

User consent is required before an account can be created. If the user wants to withdraw the constent, the user account must be deleted. 

# Privacy policy
### What data is collected? 
The app only collects the data necessary to identify users and provide the service
- Username
- Hasshed password
- User-created recipes

No additional personal information is collected. 

### Why does this need to be collected? 
The data is used to: 
- Authenticate users
- Allow users to create and manage recipes
- Distinguish between private and public content

### Data handeling and deleting
Users may delete their account at any time. When the account is deleted:
- All personal user data is removed
- All private recipes are deleted
- Public recipes remain available, but without any identifying information. Users who wish to remove public recipes must delete them before deleting their account.

# Terms of service 
### Use of the service
Everyone can use this app to find public recipes, but it requires an account and active consent to data processing as described in the privacy policy to create and manage recipes. 

### User content
Users may create both private and public recipes
- Private recipes are only visable to the users
- Public recipes are visible to everyone

### Public recipes 
Public recipes are considered public contributions. When an account is deleted, public recipes remain available but are anonymized. Users who wish to remove public recipes must delete them before deleting their account.

### Consent and deleting account
Consent is requierd to create and manage recipes. If a user withdraw their consent, this is done b deleting the account. Deleting an account removes all personal data and private recipes.
